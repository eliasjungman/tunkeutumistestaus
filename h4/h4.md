>- OWASP 2021: OWASP Top 10:2021 https://owasp.org/Top10/A01_2021-Broken_Access_Control/ (IDOR ja path traversal ovat osa tätä)

- Rikkinäinen pääsynhallinta on yleisin haavoittuvuus
- pääsynhallinta pitää huolen, ettei käyttäjä voi tehdä asioita johon hänellä ei ole oikeuksia
- Pääsynhallintaa voi ohittaa esimerkiksi menemällä osoitteeseen esim. /admin-page tms. ja voi olla mahdollista että palvelin tarkistaa vain, että käyttäjä on kirjautunut sisään.

>- PortSwigget Academy:
>- - Insecure direct object references (IDOR)
- IDOR on pääsynhallinnan haavoittuvuus, jossa sovellus ei tarkista käyttäjän oikeuksia tai tarkistaa vain että on kirjautunut sisään
- Esimerkiksi huonosti suojatussa pankissa käyttäjä voisi katsoa kuinka paljon jollakin toisella on pankkitilillä rahaa.

>- - Path traversal
- Path travelsal on haavoittuvuus, jossa käyttäjä pääsee lukemaan muita palvelime tiedostoja esim. jos url on vaikka että mikä kuva haetaan niin käyttäjä voi laittaa get requestiin ?photo=../../../etc/passwd

>- - Cross-site scripting
- Ajatellaan, että on keskustelupalsta. Joku voi kommentoida:
"\<script> alert("xss"); \</script>

Käyttäjät, jotka menevät palstalle sivu avaa ikkunan "xss". Jos tämä toimii, hyökkääjä voi tehdä kaikkea muutakin javascriptillä esim. cookiea varastajan tms.
